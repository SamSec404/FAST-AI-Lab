## 📌 Overview

This repository contains all laboratory tasks, assignments, implementations, and experiments completed during the **Artificial Intelligence (AI)** course at **FAST-NUCES**.

The purpose of this repository is to document my learning journey in Artificial Intelligence, strengthen my problem-solving abilities, and implement various AI and Machine Learning algorithms using Python and its scientific libraries.

Throughout this course, I aim to:

* Develop a strong foundation in Artificial Intelligence concepts.
* Understand intelligent agents and problem-solving techniques.
* Study uninformed and informed search algorithms.
* Learn local search and optimization algorithms.
* Explore Constraint Satisfaction Problems (CSPs).
* Gain practical experience in Machine Learning algorithms.
* Implement AI algorithms from scratch using Python.
* Build real-world problem-solving and analytical skills.
